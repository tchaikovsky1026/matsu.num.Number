# Modulo

## Introduction

除数 $m (\ge 1)$ についての剰余を考える.
$\pmod m$ が 0 以上 $m$ 未満の値を返すとする.

剰余の和と積の性質として, 次が成り立つ.

$$
\begin{split}
& ((a\bmod m) + (b\bmod m)) \bmod m = (a+b)\bmod m \\
& ((a\bmod m) \times (b\bmod m)) \bmod m = (a\times b)\bmod m
\end{split}
$$

ここで, コンピュータ等で剰余を扱うとき, 特に積を扱う場合にオーバーフローに注意が必要となる.
Java の場合, `int` 型の場合は `long` 型にキャストするなどアプローチがあるが, `long` 型の場合は `BigInteger` への変換などパフォーマンスに影響し得るような状況が起こり得る.

本ノートでは大きい形に明示的なキャストが必要のない仕組みを考えていく.


## Approach

以下では, 扱う整数は n-bit であるとする.
また, 除数としては 2 以上, $2^{n-1}$ 未満を扱う.


### 2 の累乗を法とする剰余

2 の累乗を法とする剰余は, bit 演算により簡単に実現できる.
$2^d$ ( $1\le d\le n-2$ ) を法とする剰余は $2^d -1$ との論理積をするのみでよい.
また, n-bit 系でのオーバーフローで落とされる情報は $2^n$ の倍数を表すため, 積の剰余はオーバーフローを無視して処理すればよい.


### 2 の累乗でない偶数を法とする剰余

今, 3 以上の奇数を法とする剰余を計算する方法が確立されていると仮定する.
このとき, 除数 $m$ を $m = 2^d k$ ( $k$ は3以上の奇数) と分解し, $2^d$ と $k$ を法とする剰余を求め, そこから $m$ を法とする剰余を計算する.

中国剰余定理により, $l$, $m$ が互いに素である場合, $x \equiv r\pmod m$ かつ $x \equiv s\pmod l$ となるような $x$ は法 $lm$ について一意に存在する.
今, $0\le r < m$, $0\le s < l$のとき, $0\le x < lm$ を満たす $x$ を求める問題を考える.
このような $x$ は,

$$
x = t_1 + t_2 m
$$

で一意に表される.
ただし, $0\le t_1 < m$, $0\le t_2 < l$ である.
$\pmod m$ をとることで, $t_1 = r$ が直ちにわかる.
また, 法 $l$ に関する $m$ の逆元を $m^{-1}$ とすれば,
$t_2 = (s-r)m^{-1} \bmod l$ によって $t_2$ が得られる.

$l = 2^d$ とすれば, $m^{-1}$ は容易に得られる.
$2^n$ を法とする $m$ の逆元を (符号無し整数として) 求め, 上位 bit を捨てればよい.

#### 符号無し整数としての $2^n$ を法とする $m$ の逆元
n-bit 符号無し整数系で, 奇数 $m$ の $2^n$ を法とする逆元 $y$ を求める.
これは, オーバーフローを無視して, $my = 1$ であるような $y$ を求めることである.
この問題は, 次のように整理される.

- $r = 1 - ym$ とし, $y$ を更新していくことで $r = 0$ となるものを探す. 初期値は $y=0$ とする.
- $y$ のある bit を変更したとき, $r$ はその bit から上の bit しか変化しない. したがって, $y$ の下位 bit から順番に決定していくことになる.
- $y$ の a-bit を決定しようとしているとき ( $a \ge 0$ ), $r$ は (a-1)-bit 以下はすべて 0 で埋まっている. そこで, $r$ としては (a-1)-bit 以下があふれるように `r >>> a` を考えればよい.
- $y$ の a-bit を 0 から 1 に変更したとき, $r$ から $2^a m$ を減じることになる. `r >>> a` で考える場合, `(r >>> a) - m` を計算し, 上位 bit を削除すればよい.


### 3 以上の奇数を法とする剰余

3 以上の奇数を法とする剰余は, Montgomery 乗算を利用する.
そこでまずは Montgomery 乗算について述べる.

#### Montgomery 演算
$R = 2^n$ とする.
$m$ を奇数かつ $3\le m < 2^{n-1}$ とする. このとき, $m$ と $R$ は互いに素である.
また, $m'$ を $mm' \equiv -1 \pmod R$, $R^{-1}$ を $RR^{-1} \equiv 1 \pmod m$ を満たす整数とする.
$0 \le m' < R$, $0 \le R^{-1} < m$ である.

$a$ を $0 \le a < mR$ を見たす整数とし, $a$ の Montgomery reduction $\mathrm{MR}(a)$ ( $0 \le \mathrm{MR}(a) < m$ ) を次で定義する.

$$
\mathrm{MR}(a) = a R^{-1} \bmod m
$$

$R^{-1}$ がすでに求まっていれば, $\mathrm{MR}(a)$ は $\pmod m$ を経由せずに, 次のように求めることができる
(この導出は, 後述する).

$$
\begin{split}
& t = (a+m(am' \bmod R)) / R \\
& \mathrm{MR}(a) = t \text{ or } t - m
\end{split}
$$

ただし, $(/ R)$ は整数の通常の除算である.
すなわち, $a+m(am' \bmod R)$ は $R$ の倍数である.
$t$ としては $0\le t < 2m$ の範囲であるので, 最後の分岐がある.

Montgomery reduction の逆変換を Montgomery 変換という.
$A$ の Montgomery 変換 $M(A)$ は $M(A) = \mathrm{MR}(AR^2)$ と計算すればよい.
(値の範囲については後ほど議論する.)

##### Montgomery 演算の導出
- $(a+m(am' \bmod R)) \bmod R = (a + amm') \bmod R = 0$ より, $a+m(am' \bmod R)$ は $R$ の倍数であり, $/R$ は通常の除算が可能である.
- 次に, $tR=a+m(am' \bmod R)$ について, $\pmod m$ を考えれば, $tR \equiv a \pmod m$ を得る.
したがって, $t \equiv aR^{-1} \pmod m$ である.
- さらに, $0 \le tR < a + mR$ であるので, $0 \le a < mR$ ならば $0 \le tR < 2mR$, すなわち $0 \le t < 2m$ となる.

#### コンピュータ上で扱う Montgomery 演算
$R=2^n$, $3\le m < 2^{n-1}$ とし, n-bit 整数系での処理をを考える.
Montgomery reduction は $0 \le a < mR$ の範囲の整数を扱えるため,
積の剰余を扱いやすいという効果がある.

今, $x$, $y$ を n-bit 符号無し整数で解釈し, 値としては $0 \le xy < mR$ であるとき, $\mathrm{MR}(xy)$ のための $t$ の計算を行う.

$$
t = (xy + m (xym' \bmod R)) / R
$$

ここで, $xym' \bmod R$ の計算は, n-bit で乗算した結果を符号無しで解釈すればよく, その値を $z$ とする.
$t = (xy+mz)/R$ は, $xy$, $mz$ を 2n-bit 符号無し乗算として計算したときの, 上位 n-bit 和をとり, 下位 n-bit の繰り上がりが生じるかどうか (0 に一致するかどうか) を検証して上位 n-bit 和をインクリメントすればよい.
求められた $t$ は $0 \le t < 2^n$ が確定しているため, n-bit 符号無し整数として解釈し, $m$ 以上か $m$ 未満かを判定すればよい.

コンピュータ上で扱う基本の関数として, 次の3種類を整備する.

- `mr2(x,y)` : 前記の積に対する Montgomery reduction.
    - $x$, $y$ を n-bit 符号無し整数で解釈し, 値としては $0 \le xy < mR$ である場合を扱う.
- `mr1(x)` : $x$ を n-bit 符号無し整数で解釈したときの Montgomery reduction. 値としては $0 \le x < R$ を扱う.
    - 計算方法としては, $(x + m (xm' \bmod R)) / R$ であるが, $x < R$ であるので, $x \ne 0$ の場合は $m (xm' \bmod R)$ の上位 n-bit に 1 を加えればよい.
- `m(x)` : $x$ を n-bit 符号無し整数で解釈したときの Montgomery 変換. 値としては $0 \le x < R$ を扱う.
    - あらかじめ, $R_2 = R^2 \bmod m$ を求めておく. 実装としては, `m(x) = mr2(x,R_2)` として処理する.

#### Montgomery 演算を利用した剰余計算

コンピュータ上で剰余を計算するには, 次のように行う.

- 1整数の剰余
    - $x$ を n-bit 符号無し整数で解釈し, $0 \le x < R$ であるとき, $x \bmod m$ は `mr1(m(x))` により得られる.
- 2整数の積の剰余
    - $x$, $y$ を n-bit 符号無し整数で解釈し, $0 \le x < R$, $0 \le y < R$ であるとき, $xy \bmod m$ は `mr2(m(x),y)` により得られる.
- 3変数以上の積の剰余
    - $M(xy) = \mathrm{MR}(M(x)M(y))$ という性質を利用する.
    - $a$, $b$, $c$, ... を n-bit 符号無し整数で解釈し, $0 \le a < R$, $0 \le b < R$, ... であるとき, $abc... \bmod m$ を求めるには次のように行う.
        - `a`, `b`, ... に対し, `m(a)`, `m(b)`, ... を計算する.
        - 記号的には `m(ab) = mr2(m(a),m(b))`, `m(abc) = mr2(m(ab),m(c))`, ... のように計算でき, `m(abc...)` に相当する値を得る. ただし, 結合法則が成り立つため, 中の演算順序は変更しても良い.
        - $abc... \bmod m$ は `mr1(m(abc...))` により得られる.
